What is a JWT?

JWT (JSON Web Token) is a compact, URL-safe token format used to securely transmit information between systems. A JWT typically consists of three parts: Header, Payload and Signature.

JWT Structure

  • Header - Token type and signing algorithm.
  • Payload - Claims and user information.
  • Signature - Used to verify token integrity.
